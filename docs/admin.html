抽選情報・管理用

幹部Discordの通知から開く、非掲載・復元のための管理ページです。操作できるのは、GitHubリポジトリの書き込み権限がある人だけです。

① 応募先URLをコピー

公開Websiteの各抽選カード下部にある「🔗 応募先URL」をコピーします。

https://.../application-page

② 操作を選ぶ

suppress 間違い・重複・掲載停止にする抽選

restore 間違えて止めた抽選を戻す

管理操作を開く

③ GitHubで実行

  1. 右上の Run workflow を押す
  2. action で suppress または restore を選ぶ
  3. application_url にコピーしたURLを貼る
  4. 緑の Run workflow を押す

完了すると、Websiteのデータと表示が自動で更新されます。非掲載にしたURLは翌朝の自動収集でも戻りません。
